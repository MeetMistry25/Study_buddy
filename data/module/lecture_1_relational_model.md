# Lecture 1: The relational model
topic: relational_model

## Slide 3
A relation is a table made of rows (tuples) and columns (attributes). Each row represents one record, and each column holds values of one type.

## Slide 5
A primary key is a minimal set of attributes that uniquely identifies each row in a table. A primary key cannot contain NULL values.

## Slide 6
A foreign key is an attribute in one table that refers to the primary key of another table. Foreign keys enforce referential integrity between related tables.

## Slide 8
A candidate key is any minimal set of attributes that could identify a row. A table can have several candidate keys but only one primary key. The candidate keys not chosen are called alternate keys.
